## What each route supports

- **Maintenance**: bug fixes, dependency updates, release packaging, and security upkeep.
- **Product development**: focused improvements to Bookmark Intelligence, Windows utilities, and future standalone releases.
- **Community support**: documentation, examples, testing, and Korean/English onboarding.
- **Direct crypto support**: optional BTC/Lightning contributions through a public donation page. Never send private keys or recovery phrases.

## Planned contribution tiers

## Activation checklist

1. Complete GitHub Sponsors identity, Stripe payout, and tax verification.
2. Create and verify one general-purpose tip channel (Ko-fi or Polar).
3. Create a separate BTC/Lightning donation page if crypto support is desired.
4. Add only the verified public usernames and URLs to `.github/FUNDING.yml`.
5. Replace this page's pending labels with active links and publish the final support tiers.
